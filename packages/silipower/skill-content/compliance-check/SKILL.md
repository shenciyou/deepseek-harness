# 内容合规检测

发布前先跑一遍风险清单，命中即需要修改或降级为仅草稿。

## 高危类别

- 医疗健康：不承诺疗效、不使用「根治」「包治」等绝对化表述。
- 金融投资：不承诺收益，不引导具体买卖，收益数据标注风险提示。
- 招聘或加盟：不写「月入过万」「轻松躺赚」等收益承诺。

## 引流规则

- 不使用「加微信」「私我」等直接导流时，给出对用户有具体价值的钩子。
- 不伪造平台认证、官方身份或数据截图。
- 品牌对比要可溯源，不使用未经证实的主观贬低。

## 敏感词处理

- 绝对化词：最、第一、国家级、全网最低，需替换为可验证表述。
- 诱导词：立即、马上、最后一天，需判断是否构成虚假紧迫感。
- 涉及未成年、医疗事故、灾害等话题时，默认只做客观转述。

## 输出格式

每条检测结果给出 `风险等级`、`命中文案`、`修改建议`，不直接改写原文。
